 # 🧪 Linux Basics Practice Labs

This document contains hands-on labs for the **Linux Basics** module.

These exercises are designed to reinforce the concepts covered in the module through practical terminal-based activities.

---

## 📚 Estimated Completion Time

**45–60 Minutes**

---

## 📋 Lab Index

1. Verify Your Environment
2. Navigate the File System
3. Create Directories
4. Create Files
5. View System Information

---

# 🧪 Lab 1 – Verify Your Environment

## 🎯 Objective

Become familiar with your Linux environment and verify basic system information.

---

## 📌 Prerequisites

- Linux terminal access
- Basic command-line knowledge

---

## 📝 Tasks

1. Display the current logged-in user.
2. Display the hostname.
3. Display today's date.
4. Display the current working directory.
5. Clear the terminal.

---

## ✅ Expected Outcome

You should be able to identify:

- Current user
- Hostname
- Current date
- Current working directory

---

## 🎓 Learning Outcome

Understand how to gather basic system information before starting administrative tasks.

---

# 🧪 Lab 2 – Navigate the File System

## 🎯 Objective

Practice moving between directories.

---

## 📌 Prerequisites

Complete Lab 1.

---

## 📝 Tasks

1. Display your current directory.
2. Move to your home directory.
3. Create a folder named `linux-practice`.
4. Enter the folder.
5. Return to the previous directory.
6. Return to your home directory.

---

## ✅ Expected Outcome

Successfully navigate between directories using Linux commands.

---

## 🎓 Learning Outcome

Build confidence using navigation commands.

---

# 🧪 Lab 3 – Create Directories

## 🎯 Objective

Practice creating directories.

---

## 📌 Prerequisites

Complete Lab 2.

---

## 📝 Tasks

Create the following directory structure:

```text
DevOps/
├── Linux/
├── AWS/
└── Docker/
```

Then verify that the directories were created successfully.

---

## ✅ Expected Outcome

A directory hierarchy matching the required structure.

---

## 🎓 Learning Outcome

Learn how Linux organizes project directories.

---

# 🧪 Lab 4 – Create Files

## 🎯 Objective

Practice creating files.

---

## 📌 Prerequisites

Complete Lab 3.

---

## 📝 Tasks

Inside the `Linux` directory, create:

- notes.txt
- commands.txt
- interview.txt

Verify the files were created successfully.

---

## ✅ Expected Outcome

Three empty files are present in the directory.

---

## 🎓 Learning Outcome

Understand how to create files and verify their existence.

---

# 🧪 Lab 5 – View System Information

## 🎯 Objective

Practice retrieving basic system information.

---

## 📌 Prerequisites

Complete Lab 4.

---

## 📝 Tasks

Display:

- Current user
- Hostname
- Current date
- Current working directory
- Directory contents

---

## ✅ Expected Outcome

Successfully retrieve and verify basic system information.

---

## 🎓 Learning Outcome

Become comfortable using Linux commands to inspect the current environment.

---

# 🏁 Module Completion Checklist

Before moving to the next module, ensure you can:

- Display your current directory.
- Navigate between directories.
- Create directories.
- Create files.
- View basic system information.
- Explain the purpose of each command used.

---

## 🧠 Sensei Tip

Repeat these labs without referring to the notes.

The goal is to build muscle memory with the Linux terminal. As you progress through the course, future labs will combine these fundamentals with permissions, processes, networking, scripting, and troubleshooting.
