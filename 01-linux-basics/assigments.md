# 📝 Linux Basics Practice Assignments

This document contains practical assignments for the **Linux Basics** module.

These assignments are designed to test your understanding of Linux fundamentals through hands-on practice.

---

## 📚 Estimated Completion Time

**60–90 Minutes**

---

# 📋 Assignment 1 – Explore Your Environment

## 🎯 Objective

Become familiar with your Linux environment.

---

## 📌 Tasks

- Display the current user.
- Display the hostname.
- Display today's date.
- Display your current working directory.
- List all files and directories.

---

## ✅ Expected Outcome

You should be able to identify your current environment without assistance.

---

## ⭐ Difficulty

Easy

---

# 📋 Assignment 2 – Build Your First Project Directory

## 🎯 Objective

Create a professional project directory.

---

## 📌 Tasks

Create the following structure:

```text
DevOps-Learning/
├── Linux/
├── AWS/
├── Docker/
└── Kubernetes/
```

Navigate into each directory and verify its creation.

---

## ✅ Expected Outcome

A clean directory hierarchy for future learning.

---

## ⭐ Difficulty

Easy

---

# 📋 Assignment 3 – Create Documentation Files

## 🎯 Objective

Practice file creation.

---

## 📌 Tasks

Inside the **Linux** directory, create:

- README.md
- commands.md
- notes.md
- interview.md

Verify that all files exist.

---

## ✅ Expected Outcome

Four empty files created successfully.

---

## ⭐ Difficulty

Easy

---

# 📋 Assignment 4 – Navigation Challenge

## 🎯 Objective

Build confidence navigating the Linux file system.

---

## 📌 Tasks

- Move into your Linux directory.
- Return to the parent directory.
- Move to your home directory.
- Return to the previous directory.
- Display your current location.

---

## ✅ Expected Outcome

Navigate between directories without errors.

---

## ⭐ Difficulty

Easy

---

# 📋 Assignment 5 – Mini Challenge

## 🎯 Objective

Combine everything learned in this module.

---

## 📌 Tasks

Without referring to your notes:

- Check the current user.
- Check the hostname.
- Check the current date.
- Display the current directory.
- Create a directory called `practice`.
- Move into it.
- Create three files:
  - test1.txt
  - test2.txt
  - test3.txt

- Return to the previous directory.

---

## ✅ Expected Outcome

---

## ⭐ Difficulty

Medium

---

# 📋 Assignment 6 – Interview Simulation

## 🎯 Objective

Test your theoretical understanding.

Answer the following questions without looking at your notes:

- What is Linux?
- Who created Linux?
- Why was Linux created?
- What is the Linux Kernel?
- Explain Linux Architecture.
- Name five Linux distributions.
- Why is Linux preferred for Cloud & DevOps?
- Explain the difference between Linux and Windows.

---

## ✅ Expected Outcome

Answer confidently in your own words.

---

## ⭐ Difficulty

Medium

---

# 📋 Assignment 7 – Self-Evaluation Checklist

Before moving to **Module 2**, confirm that you can:

- Explain what Linux is.
- Explain why Linux was created.
- Describe Linux Architecture.
- Identify common Linux distributions.
- Explain Linux advantages.
- Compare Linux and Windows.
- Use the following commands confidently:

  - pwd
  - ls
  - cd
  - mkdir
  - touch
  - clear
  - whoami
  - hostname
  - date
  - cal

---

## 🎯 Success Criteria

If you can complete all assignments without referring to your notes, you are ready to begin **Module 2 – Linux File System**.

---

## 🧠 Sensei's Final Advice

Don't rush through these assignments.

Treat them as if they were given by a senior engineer during your first week on the job.

The objective is not to finish quickly—the objective is to become comfortable working in the Linux terminal with confidence.
