# 🟢 Basic Interview Questions

---

## Question 1

### ❓ What is Linux?

### ✅ Answer

Linux is an open-source operating system kernel created by Linus Torvalds in 1991. It manages computer hardware and provides services for applications. Linux is widely used in cloud computing, servers, containers, and enterprise environments because of its stability, security, and flexibility.

---

### 🧠 Sensei Tip

Mention:

- Open Source
- Kernel
- 1991
- Linus Torvalds

---

## Question 2

### ❓ Who created Linux?

### ✅ Answer

Linux was created by **Linus Torvalds** in **1991** as a free and open-source kernel.

---

## Question 3

### ❓ Why was Linux created?

### ✅ Answer

Linux was created to provide a free, open-source alternative to existing operating systems, allowing developers to study, modify, and distribute the source code.

---

## Question 4

### ❓ What is a Linux Distribution?

### ✅ Answer

A Linux distribution is a complete operating system built using the Linux kernel along with software, utilities, package managers, and applications.

Examples include Ubuntu, RHEL, Debian, Fedora, Amazon Linux, and Alpine Linux.

---

## Question 5

### ❓ What are the advantages of Linux?

### ✅ Answer

Major advantages include:

- Open Source
- Security
- Stability
- High Performance
- Scalability
- Flexibility
- Strong Community Support

---

## Question 6

### ❓ What is Linux Architecture?

### ✅ Answer

Linux follows a layered architecture consisting of:

- User
- Applications
- Shell
- Kernel
- Hardware

---

## Question 7

### ❓ What is the difference between the Shell and the Kernel?

### ✅ Answer

The Shell acts as an interface between the user and the operating system.

The Kernel is the core of the operating system that manages CPU, memory, storage, and hardware resources.

---

## Question 8

### ❓ What is the difference between Linux and Windows?

### ✅ Answer

Linux is open source, highly customizable, and widely used for servers and cloud computing.

Windows is proprietary and primarily focused on desktop users and Microsoft-based environments.

---

## Question 9

### ❓ Where is Linux used?

### ✅ Answer

Linux is commonly used in:

- Cloud Platforms
- Enterprise Servers
- Docker
- Kubernetes
- Android
- Supercomputers
- Web Servers
- Databases

---

## Question 10

### ❓ Why is Linux important for DevOps?

### ✅ Answer

Linux is the foundation of most cloud platforms, containers, automation tools, and CI/CD environments.

A DevOps Engineer works with Linux almost every day.

# 🔴 Scenario-Based Questions

---

## Scenario 1

You log into a Linux server.

What is the first command you run?

### ✅ Answer

```bash
pwd
```

To verify the current working directory.

---

## Scenario 2

Before deleting files, what should you verify?

### ✅ Answer

- Current directory (`pwd`)
- File list (`ls -la`)
- Current user (`whoami`)

---

## Scenario 3

You forget where you are in the file system.

What command helps?

### ✅ Answer

```bash
pwd
```

---

## Scenario 4

You want to confirm which Linux user is currently logged in.

### ✅ Answer

```bash
whoami
```
